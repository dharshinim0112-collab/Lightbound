# Lightbound

Lightbound is a small 2D platformer made in Unity.

The main idea is that the player uses a torch to find the platforms ahead. Some platforms are hidden at first, so the player has to use the torch and move forward step by step.

## How to Play

- A / D - Move left and right
- Space - Jump
- E - Turn the torch on/off and reveal the next platform

## Gameplay

At the start, only the first platform can be seen.

Pressing E reveals the next platform. The player then has to reach that platform before the next one can be revealed.

The game has two levels. The second level continues the platforming section and ends at the final checkpoint.

## Scripts Used

The main scripts used in the final version are:

- PlayerMovement.cs
- PlatformReveal.cs
- PlatformReachTrigger.cs
- LevelComplete.cs
- SceneCompletePanel.cs
